Trouver l’email d’un dirigeant en France — Méthodes légales 2026

Comment trouver l’email professionnel d’un dirigeant français. Méthodes légales, Societe.com, Infogreffe, Dropcontact — guide complet.

Les sources pour trouver le nom d’un dirigeant

Mentions légales du site web

Obligatoires en France (LCEN), les mentions légales contiennent le nom du responsable de publication et souvent le gérant. C’est la première vérification gratuite.

Societe.com et Pappers.fr

Ces plateformes agrègent les données du registre du commerce. Nom du gérant, adresse, capital — données publiques accessibles gratuitement.

LinkedIn

Pour les entreprises avec une présence active. Le profil du fondateur ou DG est souvent public.

Reconstruction de l’email nominatif

Une fois le nom du gérant connu, Dropcontact teste les formats courants :

  • prenom.nom@domaine.fr (65%)
  • p.nom@domaine.fr (15%)
  • prenom@domaine.fr (10%)

Seuls les emails confirmés actifs sont retournés.

Questions fréquentes

La recherche d’emails de dirigeants est-elle légale en France ?

Oui pour les emails professionnels via des données publiques (mentions légales, registre du commerce). La CNIL encadre l’utilisation : intérêt légitime, opt-out disponible.

Pappers.fr est-il gratuit pour trouver les gérants ?

Oui pour les informations de base (nom du gérant, adresse). Les informations avancées (bilans, actes) sont payantes.
